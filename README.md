# Spotify Clone

A responsive Spotify-inspired web application built using **HTML, CSS, and JavaScript**. This project recreates the look and feel of Spotify's user interface, including navigation, playlists, music sections, and multiple pages.

#Live Demo

🔗 https://spotify-clone-f05z.onrender.com/

#Features

- Responsive Spotify-inspired UI
- Modern Navigation Bar
- Home Page with Music Sections
- Premium Page
- Download Page
- Help Page
- Interactive Components
- Custom Styling with CSS
- JavaScript Functionality
- Mobile-Friendly Design

# Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Render (Deployment)
- Git & GitHub

# Installation

1. Clone the repository

git clone https://github.com/Shruti123-coder1/spotify-clone.git

2. Navigate to the project folder

cd spotify-clone

3. Open `index.html` in your browser

OR

Use VS Code Live Server Extension.
